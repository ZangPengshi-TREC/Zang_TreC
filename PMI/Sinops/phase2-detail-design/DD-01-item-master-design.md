# DD-01 Item Master Detailed Design

Version: 0.1 draft
基準日: 2026-09-11
対象: Sinops-01 `item_mst.txt`, Sinops-02 `store_item_mst.txt`
スコープ: 自動補充側の IF 詳細設計。BO、WMS、棚割システム本体は対象外。

## 1. 対象と処理概要

Sinops の商品共通情報と店舗別調達情報を、TRIAL MD 基幹の標準マスタおよびコード変換テーブルから生成する。商品共通情報を先に確定し、店舗別情報は商品コード・店舗コード・仕入先コードの変換結果を参照する。

対象商品は現時点で「西友店舗に紐づく商品」を第一候補とする。ただし、抽出条件と自動発注対象フラグの保持元は未完了のため、最終出力条件は G-01 で確定する。棚割システム側のデータ生成や方式設計は本書の対象外とし、自動補充側で必要な入力契約だけを参照する。

### 3.1 分類コードの確定待ち

Phase 1 資料では、意味対応は大分類→Sinops 2、 中分類→Sinops 4、 小分類→Sinops 5 と整理されている。一方、旧変換ルールには `M 桁` / `N 桁` のプレースホルダが残っている。したがって、詳細設計の最終値は次の順で決める。

1. 最新 Sinops レイアウトから出力桁を取得する。
2. 商品マスタ統合 PJ の投影済みコードと突合する。
3. ゼロ埋め、切捨て、変換テーブル参照を分類単位で決める。
4. 大分類、中分類、小分類の親子一致を検証する。

桁数が未確定の状態で `LPAD` の桁数を固定してはならない。

## 5. 抽出・JOIN・重複ルール

### 5.1 抽出

- 西友対象店舗の一覧に存在する店舗を対象とする。
- 店舗別調達情報に紐づく商品を対象商品候補とする。
- 自動発注対象フラグの保持元と抽出タイミングは Sinops/自動発注システムとの決定後に確定する。
- 対象外商品を名称やコードの推測で採用しない。

### 5.2 JOIN

| JOIN | キー候補 | 期待件数 |
|---|---|---|
| 商品共通 | 商品共通マスタ.`id` / `code` | 商品ごとに 1 件 |
| 店舗商品 | 店舗商品マスタ.`org_id` + `item_id` | 店舗・商品ごとに 1 件 |
| 仕入先 | 取引先マスタ.`id` / `code` | 仕入先ごとに 1 件 |
| 税区分 | 商品共通マスタ.`id` + 税区分 | 商品の有効期間内で 1 件 |
| 店舗/倉庫変換 | TRIAL コード | 変換先 1 件 |

JOIN が 0 件または複数件になった場合は E003/E004 としてエラーにし、先頭レコードの採用はしない。

### 5.3 発注単位の共通値

商品共通の発注単位は、店別調達マスタを商品コード単位で集計し、値ごとの店舗数を数えて最多値を採用する。同数の場合の決定方法は `TBD` とする。店舗別出力では、各店舗の店別発注単位を優先する。

## 7. 単体テスト骨子

- 商品コードの先頭 0、右端 13 桁、インストアコード、空値
- 商品対象範囲に含まれる/含まれない店舗・商品
- 商品階層の親子一致、不一致、桁超過、変換テーブル未登録
- 発注単位の最多値、同数、店舗別値、欠損
- 賞味期限の単位変換と販売許容日数の 180 日境界
- 税抜価格の 8%/10% と端数処理
- 仕入先・出荷センター・納品経路のコード変換
- 0 件、JOIN 0 件、JOIN 複数件、重複キー、再送
