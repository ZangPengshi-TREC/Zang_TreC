## 2. 入荷予定（Sinops-12）

更新履歴要点（基幹切替 2023-10〜2024-03）:

- 伝票No / 入荷予定日 / 発注予定日 / 便区分 / 入荷予定数量
- `2024-03-01`: 伝票No セット条件から「売上区分=7 本部」を外す

目标项目（与 Phase1 一致）8 项。

升级后编辑规格（西友 AS-IS 提示，TRIAL 设计时需等价确认）:

| 项 | 规则 |
|---|---|
| 入荷予定数量 | `発注数量 × 発注単位数`（基幹切替后数量变单位数，必须換算バラ） |
| 入荷予定日 | 納品日付空白 → 納品予定日付 |
| 発注日 | 発注日付空白 → 発注予定日付 |
| 便区分 | 便コード `0` → `9` |
| 伝票No | 伝票管理番号未設定 → 半角スペース；注记称目前入荷予定/実績紐づけに伝票番号は使用していない |
| コメント | 売上区分 0通常/1返品/2特売/7本部 |

Phase1 状态: 数量写「バラ直接」、便区分 ✕GAP、コメント有コード変換；**未写** ×発注単位・0→9・日付 fallback。

**DD 影响**: レイアウト不变。数量规则与 Phase1「バラ直接」兼容，但必须确认 TRIAL 源是否已是バラ；若源是「発注単位数」则要乘。便区分默认值（0→9）与 G-03 一并定。
