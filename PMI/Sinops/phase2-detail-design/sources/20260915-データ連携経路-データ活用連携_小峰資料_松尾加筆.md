## 2. 右注（原文転記）

① 現状 Inunaki には VPN 経路はないので新たにデータセンタの RTX と構築

② Inunaki のプライベートアドレスをアサイン

③ Inunaki のストレージに PSC（PrivateServiceConnection）を作成

※ただし、リソース名（=DNS登録）は 例) `inunaki.storage.googleapis.com` などとする。`storage.googleapis.com` での登録は NG

before/after で `storage.googleapis.com` の名前解決が変わらないことを必ず確認

④ Inunaki のプライベートネットワークをデータセンタに広報

### 以降ネットワーク作業

- PSC で得られた IP アドレスをセンター間 FW にて変換
- 西友 DNS で例) `inunaki.storage.googleapis.com` を変換アドレスで登録
- DataSpider は `inunaki.storage.googleapis.com` をターゲットに設定を行う
- ※西友起点での通信のみのため TRIAL 側での DNS 登録は不要

## 3. アーキテクチャへの織り込み（2026-09-15）

- 申請する IF クラウド機 = TRIAL GCP の **ProjectD（Seiyu_Order）**。図の既存 A/B/C に並列する新規 Project。
