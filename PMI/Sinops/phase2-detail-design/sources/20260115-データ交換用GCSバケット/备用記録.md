## 2. ザックリフロー（現行運用の読み）

1. 各 SYS 窓口が IF 内容を協議し、`SEIYU-TRIALインターフェース管理台帳` に書く（共有ドライブ「03_役割_STAND TOGETHER」。権限なければ申請）
2. 台帳を埋めたら Chat スペース「seiyu-trial data-exchangeに関して」へ連絡
3. システム管理部がフォルダと権限を作る。準備できたら Chat で返す
4. 各 SYS がフォルダとの連携を開発。西友は DataSpider、TRIAL は業務 SYS ごと
5. 本番の取得・退避は各自。障害は台帳の担当者間。GCP コンソールは上記 PJ

文字コード: **UTF-8**。書き込みはサービスアカウントのみ。読み込みはグループ可。

## 3. フォルダ命名（西友 IF ルール）

`[SYS ID from]_[SYS ID to]_[3桁連番]`

例: `SY0001_INU0001_001` id_pos、`SY0001_INU0001_002` 店舗マスタ、`SY0002_SZ0001_001` 惣菜発注。

日別サブフォルダ（`20251009` 等）は個別ルール。ファイル名の復旧（上書きか新規か、全日か差分か）は IF ごとに窓口同士。一覧はスプレッドシート。

Sinops 01–25 の SYS ID / 連番は台帳採番後。本 PPT の例を IF ID として使わない。
