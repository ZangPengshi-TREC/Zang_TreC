### 【スライド 1】背景・なぜ新しいクラウド機を申請するか　／　翻到第 1 页

#### 中文

各位好。今天说明 **SCM連携クラウド機** 的 GCP 环境申请。文件和放映都是七页：先讲背景，再讲为什么用 Cloud Run，然后是构成、每天怎么跑、规格、费用，最后和 GKE 对比。

先看背景。现在推进的是西友与 TRIAL 的 **MD 基幹統合、PMI 课题的 Phase2 阶段**。每天要把大阪集计侧的数据交到西友侧；TRIAL 与西友之间的正本连携路径是 **seiyu-trial-data-exchange**。型转换和共通化，方针上放在 TRIAL 侧吸收。如果按课题拆多个项目，SCM 统一连携面会裂开，所以要收敛成一台机。

因此需要：在 TRIAL GCP 上申请 **一台 SCM 连携机**；负责见积里的 **Layer①**——取得、转换、配置的批处理；**付帯 GCS（元データ）** 和 Cloud Run（处理）一体申请；只把最终 TXT **一方向**交到 **seiyu-trial-data-exchange**。

为什么说是「新机」。Layer① 是这次要申请的 TRIAL 云机；Layer②③ 是西友 Azure 的 DataSpider，**用既存即可**。DSS 只做全字段通过，转换在 Layer①。本机不挂持久盘，永续只在 GCS。这也是 **PMI 课题 Phase2** 的执行基盤前提。

申请什么、不申请什么。申请：一个项目、Cloud Run Jobs、**本PJ GCS**、Scheduler、Workflows、**STS**（Storage Transfer Service）等。不申请：GKE、本机持久磁盘、DataSpider、以及 **seiyu-trial-data-exchange 本体**——该 GCS 要向松尾另行申请。

一句话：**为了跑通 TRIAL 与西友之间的数据连携，TRIAL 侧需要带转换的统一 IF 基盤，所以申请新建一台 SCM連携クラウド機。**

接下来讲，这台机用什么执行基盤。

そのため必要なのは、TRIAL GCP 上の **SCM 連携機を 1 台**。見積（みつもり）の **Layer①**、つまり取得（しゅとく）・変換・配置（はいち）のバッチです。**付帯（ふたい）GCS（元データ）** と Cloud Run（処理）を一体で申請し、最終（さいしゅう）TXT のみ **seiyu-trial-data-exchange** へ一方向（いちほうこう）納品（のうひん）します。

申請する／しない。申請するのは 1 プロジェクト、Cloud Run Jobs、**本PJ GCS**、Scheduler、Workflows、**STS**（Storage Transfer Service／ストレージ転送サービス）など。申請しないのは GKE、本機永続ディスク、DataSpider、**seiyu-trial-data-exchange 本体**です。seiyu-trial-data-exchange は松尾さんへ別途申請します。

一言で言うと、**TRIAL と西友の間のデータ連携を回すため、TRIAL 側に変換付きの統一 IF 基盤が要ります。だから新規 1 プロジェクトの SCM連携クラウド機を申請します**。

### 【スライド 2】なぜ Cloud Run Jobs を採用するか　／　翻到第 2 页

#### 中文

第二页是技术判断。本件不是常驻 API，而是 **需要时才跑的日次文件 IF 批处理**。所以用 **Cloud Run Jobs**，**不上 GKE**。

四个観点。一，動き方：启动→处理→结束，空闲可停；GKE 容易常设集群，批处理易留固定费。二，工作内容：抽出、转换、GCS 推拉；GKE 更适合微服务和常驻 API。三，存储：ステートレス、正本只在 GCS；GKE 往往带节点和卷运维。四，运维费用：这页卡片写的是 Cloud Run **生产环境每天 3 小时、保管三十天，月约 ¥25,069**（転送占大半）。GKE 卡片上的「常驻案月多约两万」是概数，精确对照在最后一页。

收束：**不是常开的底座，而是需要时才跑的批处理，所以采用 Cloud Run Jobs。GKE 是常设集群前提，对本 IF 机过重。**

接下来看构成图。

2 枚目は技術（ぎじゅつ）判断（はんだん）です。本件は常駐（じょうちゅう）API ではなく、**必要なときだけ動く日次ファイル IF バッチ**です。そのため **Cloud Run Jobs** を採用し、**GKE は申請しません**。

三套放在一起比。保管和传输大约 **¥24,894**，三边一样。一个月：Cloud Run **¥31,607**，Autopilot 三个集群约 **¥53,213**，Standard 三台一直开着约 **¥108,607**。一年约 **¥379,287**、**¥638,556**、**¥1,303,000**。差在集群管理费。所以用 Cloud Run，不申请 GKE。请审议。谢谢。
