## 背景スライドの要旨（口頭）

- 西友 MD 基幹統合／自動補充 Sinops 第2段階
- 大阪集計→西友へ日次納品；正本は西友連携 GCS；変換は TRIAL Layer①
- 課題別 PJ 分割は不可 → SCM 連携機 1 台に集約
- Layer②③＝西友 DSS（別 Spec）；本機ディスクなし
- 申請：1 PJ・Cloud Run・自有 GCS 等／不申請：GKE・DSS・連携 GCS 本体
