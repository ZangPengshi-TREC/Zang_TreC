## 結論

### 中文

生鲜要调查的东西多、风险相对较高，所以全部 IF 按同一套节奏走：**调查 10/12～10/21 → 概要完成 10/27 → 详细完成 11/16 → 开发完成 12/3 → 单体完成 12/18**（12/20 是周日）。

入荷三本调查比较重，调查放到 10/21。每本 IF 在 Mapping 后做 review，期限 **10/22**，全部合计不超过 **1.0人日**，不占额外日历，也不计入计划工数。

统合转换是 TRIAL 自动订货的内部处理，**不做 Mapping，也没有单独的 review**，从概要设计开始。

概要设计是在调查和详细设计之间新增的一段（IF 布局的“概要”：收发、频率、时刻、件数、各层范围）。它的工数**从 Layer① 详细设计里切出来**，总工数不增加。见积本体 157.5 人日里，统合转换的 Mapping 5.0 人日不再做，所以计划工数是 **152.5人日**。

臧鹏仕的详细设计 10/28～11/16 正好是 14 个工作日，工数也是 14 人日，**没有余量**。

日历按周末休息。10/12、11/3、11/23 是日本祝日，这次开工日就是 10/12，所以这三天按出勤放。

### 日文

生鮮は調査すべきことが多くリスクが高い。そのため全IFを同じ節目で組む。**調査 10/12〜10/21 → 概要完了 10/27 → 詳細完了 11/16 → 開発完了 12/3 → 単体完了 12/18**（12/20は日曜）。

入荷3本は調査が重いので、調査を10/21まで置く。各IFのレビューはMapping後で、期限は **10/22**。合計 **1.0人日以内** で、カレンダーは足さず、計画工数にも含めない。

統合変換はTRIAL自動発注の内部処理なので、**Mappingは行わず、単独のレビューもない**。概要設計から着手する。

概要設計は調査と詳細設計の間に置いた段階（IFレイアウトの「概要」。送受信・頻度・時刻・件数・レイヤー別スコープ）。工数は**Layer①詳細設計から切り出す**ので、総工数は増えない。見積本体157.5人日のうち、統合変換のMapping 5.0人日は行わないので、計画工数は **152.5人日**。

臧鹏仕の詳細設計は 10/28〜11/16 の14営業日に対して工数も14人日。**余白がない**。

カレンダーは土日だけ休む。10/12、11/3、11/23 は日本の祝日だが、着手日が 10/12 なので稼働日として置く。
