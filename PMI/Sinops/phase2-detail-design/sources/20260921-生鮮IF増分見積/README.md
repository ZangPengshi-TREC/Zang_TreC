## 7. 説明話術の作り方（今後の共通ルール）

今後、本フォルダおよび類似の説明話術を作るときは次を守る。

1. **中日双语**：同じ節に中文（照着念／要点）と日文（対外読み上げ）を並記する  
2. **日文の振り仮名**：常用しにくい漢字には振り仮名（Markdown は `漢字（かな）`、HTML は `<ruby>`）  
3. **成果物は2形式**：`.md` と `.html` を必ずセットで出す  
4. **用語**：簡体字混入禁止（例：一览→一覧、精查→精査）。中語直訳を避ける（双源→2系統ソース、着地→連携先、上げ→アップロード、未凍結→未確定）  
5. **範囲の言い切り**：Phase2＝詳細設計・開発・単体まで。結合以降は「含まない」と明示
