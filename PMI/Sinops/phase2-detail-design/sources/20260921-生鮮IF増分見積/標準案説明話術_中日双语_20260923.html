1. 先に言う前提（数字より先）

请先听前提，再听数字。

主数据（マスタデータ）这部分的本数已在 2026-09-29 判定，不要再说「生鲜整体风险仍很大」。

提示值是判定后的工数，不是确定请负额。残件或判定覆了就再見積。

日文（読み上げ）

数字すうじの前に、前提ぜんていをお伝えつたえします。

マスタデータ（流用りゅうよう／新規しんき）の本数ほんすうは 2026年9月29日 に判定はんてい済みです。「生鮮せいせんの不確実性ふかくじつせいがいまも大きい」という書き方かきかたはしません。

提示値ていじちは判定はんていを織り込んだおりこんだ工数こうすうであり、確定かくてい請負うけおい額ではありません。

残件ざんけんが顕在化けんざいかするか、判定はんていが覆ったくつがえった場合ばあいは、再見積さいみつもりとします。

2. 判定の要点

中文
  • 店铺系マスタ・实绩 12本流用（本体IF不另做，B2（主数据本体IF）＝0）
  • 发注劝告当日／翌日：两个文件，工数按 1.5本（当日＝1、翌日以降＝0.5）
  • 生鲜劝告→发注统合转换新規。现在的生鲜→统合 IF 不能用，参照非生鲜发注劝告
  • 入荷实绩：供应商流用，伝票区分差分、PC/CK振替
  • 入荷预定（nyuka_yotei）・发注日程（sii.txt）：供应商流用。PC/CK 在别的 SQL，Layer① 做 DBGET。作成时刻略不稳，含等待
  • 仓库：无DC在库 → 対象外
  • 残件：水煮相当、GCS、伝票区分精査、生鲜劝告→发注统合转换与发注IF的项目差
日文（読み上げ）
  • 店舗てんぽ系は 12本流用りゅうよう。本体ほんたいIFは置きませんおきません。B2（マスタ本体IF）は0です。
  • 発注勧告はっちゅうかんこくの当日とうじつ・翌日よくじつ以降いこうは、ファイルは2つ、工数こうすうは 1.5本換算かんさん（当日＝1、翌日以降＝0.5）です。
  • 生鮮勧告せいせんかんこく→発注統合変換はっちゅうとうごうへんかんは新規しんきです。いまの生鮮せいせんから統合とうごうへ出すIFは使えません。非生鮮ひせいせん発注勧告はっちゅうかんこくを参照さんしょうします。
  • 入荷実績にゅうかじっせきはベンダー流用りゅうようで、伝票区分でんぴょうくぶんの差分さぶんとPC／CKの振替ふりかえです。
  • 入荷予定にゅうかよてい（nyuka_yotei）と発注スケジュールはっちゅうスケジュール（sii.txt）はベンダー流用りゅうようです。PC／CKは別SQLにあり、Layer①でDBGETします。作成時刻さくせいじこくはやや不安定ふあんていなので、待ち合わせまちあわせを含みます。
  • 倉庫そうこは DC在庫ざいこなしで対象外たいしょうがいです。
  • 残件ざんけんは、水煮みずに相当そうとう、GCS、伝票区分でんぴょうくぶんの精査せいさ、生鮮勧告せいせんかんこく→発注統合変換はっちゅうとうごうへんかんと発注はっちゅうIFの項目こうもく差です。

3. 本案（標準案）が置いている前提

中文

标准案的前提就是上述判定。

流用覆了、水煮要做IF、生鲜劝告→发注统合转换的布局和发注 IF 差很大、GCS 或伝票区分明显变重时，今天的数字无效，需要再見積。

日文（読み上げ）

標準案ひょうじゅんあんが置いている前提ぜんていは、9月29日の判定はんていが成り立つなりたつ場合ばあいです。

流用りゅうようが覆るくつがえる、水煮みずに相当そうとうが要IFになる、生鮮勧告せいせんかんこく→発注統合変換はっちゅうとうごうへんかんのレイアウトが発注はっちゅうIFから大きく外れるはずれる、GCSや伝票区分でんぴょうくぶんが想定そうていより重い場合ばあいは、本日ほんじつの提示値ていじちは無効むこうとなり、再見積さいみつもりとします。
