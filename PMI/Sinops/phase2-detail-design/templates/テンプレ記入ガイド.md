## シート構成

| シート | 書くこと |
|---|---|
| 00 表紙 | 名称、方向、対象レイヤー、担当、改訂履歴（**IF No. は載せない**） |
| 01 概要 | 送受信、頻度、時刻、件数、レイヤー別スコープ |
| Data Flow | **必須:** 図は draw.io。テンプレ `templates/データフロー図.drawio`（ページ名 `Sinops-IF-NNN_業務名`）。Excel の Data Flow シートへ図を貼る。箱ごとに Server名／接続先／テーブル名／ファイル名。未確定は TBD-DF-xx |
| 02 Layer① | 抽出/受信、**型変換・選別・編集**、ファイル名、GCS、STEP（10 刻み）。GCS 物理名 `{論理ベース}_YYYYMMDDhhmmss` |
| 03 Layer② | マスタのみ。**全フィールド Intake**。11/12/24/25 は **対象外** |
| 04 Layer③ | DSS。**転送・配置のみ**。型変換は①へ |
| 05 項目マッピング | **名前:** `05_項目マッピング(Layer①|②|③)`（括弧＋Layer）。L①＝変換の正。L②＝Intake通過。L③＝DSS直連携 |
| 07 ファイルレイアウト | **名前:** `07_ファイルレイアウト({系})`。例: `(TRMD基幹)` / `(DWH)` / `(Sinops)`。必要な系だけ残す |
| 08 エラー | 本 IF 固有 |
| 09 TBD | 全件クローズが詳細設計完了条件 |

欠番: `06` シートは無い。変換は `05` のマッピング／変換ルール列で持つ。
