# IF詳細設計書テンプレート（2026-09-18）

原本: `templates/IF詳細設計書_20260918.xlsx`  
サンプル中身: **BO-33**（国内流通商品マスタ）。自動補充に使うときは IF ごとにコピーして差し替える。  
欠番: `06` シートは無い。変換は `05` の「変換ルールID」列で持つ。`Data Flow` は空。

未確定は空欄にしない。`09` に TBD-xx を起票し、本文に同じ ID を書く。版は初版 1.0、レビュー 1.1、仕様変更 2.0＋変更管理表 D-5。期限は D-4 の 9/30・10/16 に合わせる。

## シート

| シート | 書くこと |
|---|---|
| 00 表紙 | 名称、方向、対象レイヤー、担当、改訂履歴（**IF No. は載せない**） |
| 01 概要 | 送受信、頻度、時刻、件数、レイヤー別スコープ |
| Data Flow | **必須:** 図の箱ごとに Server名（またはマネージドサービス名）／IPまたは接続先／テーブル名／ファイル名。未確定は TBD-DF-xx（09 と同一ID）。マネージドでIPが無い場合は「—」＋接続経路を備考。発注勧告は図＋ノード定義表あり |
| 02 Layer① | 抽出/受信、**型変換・フィールド選別・コード変換・編集**、ファイル名、GCS、STEP（10 刻み）。**変換の正はここ** |
| 03 Layer② | マスタのみ。**全フィールド Intake（型変換・選別なし）**。11/12/24/25 は **対象外** |
| 04 Layer③ | DSS。**転送・配置のみ（全フィールド）。型変換・項目選別・コード編集は書かない**（①へ）。往路は Sinops 取込、復路は連携用 GCS 配置 |
| 05 項目マッピング | **L①／L②／L③ の3シートに分ける。** `05_項目マッピング_L①`＝型変換・選別・編集（変換の正）。`L②`＝Intake全項目通過（無ければ対象外）。`L③`＝DSS転送全項目通過（送信元＝受信先の直連携）。Phase1 GAP の変換は **L① のみ** |
| 07 ファイルレイアウト | 物理仕様。双方向ならシート複製 |
| 08 エラー | 本 IF 固有。共通は A-7 |
| 09 TBD | 全件クローズが詳細設計完了条件 |

テンプレ右側の Sheet①〜④（IN テーブル定義・SQL）はこのブックに無い。JOIN が要る IF は 02 の処理フローと 09 に残す。

## 臧担当での切り方

1 IF = 1 ブック。Layer1 と Layer3 は同じブックの 02 と 04。WBS の 2.1.xx と 2.3.xx を分冊しない。  
**命名:** `DD/Sinops_IFレイアウト(業務名).xlsx`（例: 発注勧告 → `Sinops_IFレイアウト(発注勧告).xlsx`）。

| IF | ブック | 方向 | ② |
|---|---|---|---|
| 24 | `DD/Sinops_IFレイアウト(発注勧告).xlsx` | 復路。**通常採用** | 対象外 |
| 25 | `DD/Sinops_IFレイアウト(発注勧告翌日以降).xlsx` | 復路。フローは24と同一。**障害時、または当日未作成時に昨日ファイルで代替** | 対象外 |
| 11 | 未作成 → `DD/Sinops_IFレイアウト(入荷実績).xlsx` | 往路 | 対象外 |
| 12 | 未作成 → `DD/Sinops_IFレイアウト(入荷予定).xlsx` | 往路 | 対象外 |

24（版 0.12）・25（版 0.8）はテンプレ適用済。確定は数量、納品日、Ordertype（勧告の西友ライン＝部門→ZONE。商品マスタは見ない）、Layer① 共通判定。店CD・仕入先・商品の紐付けはマスタ統合で解決（本IFは独自変換しない）。更新日・締切（TBD-19）は TBD。
