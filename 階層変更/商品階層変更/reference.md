# 商品阶层变更参考

## 条件矩阵

| 条件 | 为“有”时追加的工作 |
|---|---|
| 新规部門 | 部門相关表、ダミ棚、惣菜部門LIST、KPI除外候选等 |
| 部門－ゾーン关系变更 | WEB登记、备份、ゾーン变更、TBL同步与验证 |
| 新规ゾーン | 追加VIEW/TBL定义确认 |
| 惣菜对象 | 设置ロス、曜日构成比、ABC及星期一JOB判定 |
| 寿司对象 | 当期表备份、事前SELECT、星期二SQL/JOB判定 |
| 野菜・果物对象 | 周间计划参数及星期三JOB判定 |
| 需要预测对象 | 季节系数等影响调查与批准 |
| KPI除外部門追加 | BUMON_JYOGAI更新及各服务器同步 |
| DIV变更 | DIV相关Master和下游影响确认 |

条件为“无”时应显示“对象外”，不得把行删除；这样才能保留审计依据。

## 阶段门禁

### Gate A：资料冻结

- 新旧阶层文件唯一且版号已记录。
- 五层CD与名称齐全。
- ProductsSet期号和环境明确。

不满足时：停止继承关系整理。

### Gate B：继承关系批准

- 五层均独立比较。
- 新规、移动、统合和分割已复查。
- ProductCD/JAN结果与名称推断差异已处理。
- 占比低于70%的节点已人工确认。
- WEB登记用1:1数据无重复、无空栏。

不满足时：禁止WEB登记。

### Gate C：切换前

- 商品阶层最终确认完成，未确定0件。
- 新阶层未提前出现在正式DB/TBL。
- 所有写入SQL均有备份、事前SELECT、预计件数和回退SQL。
- 参数文件已批准。
- JOB执行/跳过已根据D的星期确定。

不满足时：禁止当日变更作业。

### Gate D：切换后

- 商品阶层处理状态全部结束。
- DB、SMART TBL和WEB均可查到新阶层。
- 继承后参数与批准值一致。
- 源件数、处理件数、完成件数一致。
- 一时crontab/JOB已停用或清理。

不满足时：禁止完了联络。

## 一行一检查的字段

实施清单每行固定使用：

| 字段 | 内容 |
|---|---|
| Check | 未实施/完成/跳过/异常 |
| No. | 连续编号 |
| Phase | 所属阶段 |
| Timing | D-7、D-2、D-1、当日时刻、D+1等 |
| Decision | 必须/实施/条件付/对象外 |
| Type | CHK/XLS/SQL/CMD/WEB/JOB/GATE |
| Action | 单一动作 |
| Command/Operation | 一条命令、一个SQL语句或一次WEB操作 |
| Expected | 可观察的正常结果 |
| Evidence | 文件、截图、日志、件数或批准记录 |
| Failure action | 停止点、联络对象和回退方式 |

若一个单元格中出现 `&&`、`;`、多条SQL或多个按钮动作，应判断能否拆成独立检查行。

## SQL与命令安全

1. 先确认环境、主机、数据库、schema、表和对象期间。
2. 备份表名必须带本次日期或变更ID，执行前确认不存在同名表。
3. UPDATE/INSERT/DELETE前先以相同WHERE执行SELECT并记录件数。
4. 写入后立即用独立SELECT验证，不以“命令无错误”代替业务验证。
5. 不自动执行生产写入；需要用户明确授权。
6. 不自动执行数据库迁移、权限变更或认证逻辑变更。
7. 历史命令中的IP、pod名、路径和列名仅作候选，必须与当前环境核对。

## 继承关系质量检查

- 新阶层路径在同一层唯一。
- “変更なし”必须同时满足CD路径与名称路径一致。
- 同名节点优先在旧阶层全局精确匹配。
- 父节点推定不得直接污染子节点结果。
- 子节点多数关系可用于复核父节点，但少于2票不得自动覆盖。
- SQL主来源并列时保留人工判断依据。
- 统合/分割不得只记录一个来源而丢失其他重要来源。
- 每次人工覆盖都必须留下理由和确认人。

## 切换后最低验证集

### DB

- 新部門：1件。
- 新ミニ部門及以下：目标路径至少1件。
- 新部門下商品：至少1件，且数量与预期相符。

### SMART TBL

- BUMON_NAME：目标部門1件。
- 各下层名称TBL：目标完整路径1件。
- 部門－ゾーン：需要变更时目标组合1件。

### WEB与参数

- 新阶层可检索。
- 关键参数值与批准文件一致。
- 不应继承的旧阶层值未误带入。
- 对象JOB状态符合星期规则。

## 异常记录

至少记录：

- 发生时间和发现步骤
- 操作者
- 环境和对象
- 实际命令/SQL/WEB动作
- 期待结果与实际结果
- 写入前后件数
- 已完成范围
- 是否回退及结果
- 联络对象
- 再开条件
