# 店舗階層変更资料生成

## 目标

将同时包含旧编成与新编成的店舗編成Excel，整理成模板规定的五个Sheet：

1. `新旧参照(支店)`：逐店展示旧／新支店和支社
2. `新旧参照(エリア)`：逐店展示旧／新エリア、支店和支社
3. `エリア`：新エリア与旧エリア、参照继承来源
4. `支店`：新支店与旧支店、参照继承来源
5. `支社`：新支社与旧支社、参照继承来源

## 输入确认

执行前必须确认：

- **源文件**：含旧列与新列的店舗編成 `.xlsx`
- **模板文件**：含上述五个Sheet的 `.xlsx`
- **输出路径**：不得覆盖源文件或模板

若缺少任一项，询问用户。若文件已由当前对话明确给出，不重复询问。

## 固定业务规则

1. 以 `店舗CD` 作为新旧店铺对应的事实主键。
2. 源Sheet必须能识别以下字段：
   - 旧：`支社CD (旧)`、`支社名(旧)`、`支店CD(旧)`、`支店名(旧)`、`エリアCD(旧)`、`エリア名(旧)`
   - 新：`支社CD(新)`、`支社名(新)`、`支店CD(新)`、`支店名(新)`、`エリアCD(新)`、`エリア名(新)`
   - 店铺：`店舗CD`、`店舗名`
3. 遇到“閉店店舗の編成が必要な場合”标记时，标记以下的闭店参考表不进入主要结果。
4. 新节点的参照来源按该节点下相同 `店舗CD` 的旧节点多数决定。
5. 主继承来源占比低于70%时必须标记“要確認”，不能无提示地确定继承关系。
6. CD为空的本部／特殊节点，只有完整名称路径也一致时才判为同一节点。
7. 比较必须使用完整路径：
   - 支社：支社
   - 支店：支社→支店
   - エリア：支社→支店→エリア

## 変更パターン

| CD路径 | 名称路径 | 判定 |
|---|---|---|
| 一致 | 一致 | `変更なし` |
| 一致 | 不一致 | `名称変更(CD移動要確認)` |
| 不一致 | 一致 | `名称一致(CD変更あり)` |
| 不一致 | 不一致 | `新規` |

仅 `新規` 填写模板中的“参照”列；参照来源必须来自同一批店铺的旧节点。

## 执行

使用随Skill提供的脚本，不要每次临时重写生成逻辑：

```bash
python3 scripts/build_store_hierarchy.py \
  --source "/path/to/店舗編成.xlsx" \
  --template "/path/to/店舗変更新旧参照テンプレート.xlsx" \
  --output "/path/to/店舗変更新旧参照.xlsx"
```

依赖：Python 3、`openpyxl`。

## 输出要求

- 保留模板的Sheet名称、表头、颜色、列宽、冻结窗格和筛选。
- 标题中的期别改为源文件对应的新旧期间；无法可靠识别时使用“現階層”“新階層”，不要猜期别。
- 变更行的新阶层区域使用淡黄色。
- 不保留模板中的失效公式；结果写为确定值。
- “新規”行的変更パターン单元格注释必须记录：
  - 参照依据
  - 主来源店铺数／总店铺数
  - 主继承率
  - 是否要确认

## 交付前检查

必须全部通过：

- [ ] 两个逐店参照Sheet的店铺数相同
- [ ] `店舗CD` 无重复
- [ ] 闭店参考表未混入
- [ ] 新支店／新エリア的参照来源可由店铺CD追溯
- [ ] 所有筛选范围覆盖实际数据
- [ ] 工作簿中不存在 `#REF!`
- [ ] 工作簿中不存在残留计算公式
- [ ] 输出文件可重新用 `openpyxl` 打开

交付时报告：有效店铺数、阶层变更店铺数、支店变更数、エリア变更数、新规节点及其参照来源。
